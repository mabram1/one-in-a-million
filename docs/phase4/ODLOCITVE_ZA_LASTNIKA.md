# Sprejete odločitve za Phase 4

Ta datoteka je kratek slovenski povzetek. Tehnične podrobnosti so v oštevilčenih dokumentih.

## Kaj sledi

### Phase 4A

- splash in resnično nalaganje;
- kratek intro;
- onboarding za shake/GO/tilt;
- dovoljenje za senzorje ob pravem trenutku;
- nova začetna stran oziroma Main Hub;
- jasna oznaka Desktop Demo.

### Phase 4B

- Guest profil;
- XP in level;
- coins in gems;
- lastništvo ter opremljanje dodatkov;
- Store;
- Profile;
- ločeni rekordi za motion, touch in desktop tipkovnico.

## Ekonomija

- Začetek: **1.000 coins in 20 gems**.
- Coins se redno zaslužijo z igranjem.
- Gems so redkejši in se dobijo pri level mejnikih ter kasneje pri Daily Challenge.
- Nakupi so samo kozmetični.
- Noben dodatek ne vpliva na hitrost, trke ali ranking.
- Cene obstoječih 16 dodatkov ostanejo take, kot so določene v katalogu.
- Pravi denar v Phase 4 ni vključen.

## Zakaj pravi denar še ni vključen

Pred aktivacijo potrebujemo Google/Apple product ID-je, lokalizirane cene, preverjanje računov, restore-purchases, refund/revocation pravila in pravne povezave. Claude lahko pripravi vmesnik za prihodnji billing adapter, vendar uporabnik še ne sme videti lažne blagajne.

## Desktop rezultati

- Mobile motion je glavna tekmovalna kategorija.
- Mobile touch je ločena kategorija.
- Desktop tipkovnica je Demo/Practice.
- Desktop rekord se nikoli ne meša z rezultati mobilnih senzorjev.
- Desktop ne ustvarja trajnih economy nagrad, ker bi se lahko coins prelahko farmali s tipkovnico.

## Neobvezni gameplay dodatki

Po Phase 4:

1. sticky mucus slowdown;
2. cilia lateral push;
3. rival/ghost sprite;
4. ločen boost-charge pickup.

Za sticky/cilia grafika že obstaja, vendar njune fizikalne vrednosti še potrebujejo testiranje na telefonu.
