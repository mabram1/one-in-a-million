# One in a Million — How to Play Kit

Five humorous, mobile-first onboarding cards using the accepted Spermy rig, HUD, WBC, pickup, and human-ovum assets.

## Included

- Five English 1080×1920 reference screens.
- Five Slovenian 1080×1920 reference screens.
- English and Slovenian localization JSON.
- English and Slovenian contact-sheet previews.
- Claude Code implementation notes.

## Card sequence

1. Shake to charge.
2. Stop in the green GO zone.
3. Tilt to steer.
4. Shake means straight; release to aim.
5. Reach the glowing ovum and begin a safe Practice run.

## Tone

The copy is playful but functional. Each joke supports the instruction:

- “Yes, enthusiasm counts.”
- “Too early: sleepy. Too late: crispy.”
- “Your phone moves. You don’t have to.”
- “Multitasking is overrated.”
- “No pressure. You’re only one in a million.”

## Implementation rule

The full-screen PNG files are reference comps, not flattened production UI. Build the screens responsively in DOM/CSS, reuse the accepted game assets, and load all text from localization JSON.
